Philosophy
Observability should be interactive, not forensic

Nothing important should be invisible

Every network request, database write, event, and exception is captured and surfaced in real time.

Seconds, not hours

Answer "what just happened?" immediately. No digging through logs, no rebuilding mental models.

Zero overhead in production

The noop artifact mirrors the full API with empty bodies. R8 optimises it away completely.

No vendor lock-in

Depends on no tracing SDK. A ~15-line adapter bridges whatever tracer you already run.

Module structure

  • ›alohomora — Full debug-time library: Room DB, TCP server, Koin DI, Compose UI
  • ›alohomora-noop — Production no-op mirror. Same API, zero overhead. R8-optimised away.
  • ›alohomora-common — Shared data models, Room entities, binary protocol types
  • ›alohomora-ui — Shared Compose UI components including the trace waterfall
  • ›Gradle plugin — Code-generates build metadata from Git at build time
  • ›Desktop app — Standalone Compose Desktop. Connects via ADB.
Setup
Up and running in 5 minutes

Add the dependency, optionally apply the Gradle plugin for build metadata, and start capturing.

1

Add the dependency

Use debugImplementation for the full library and releaseImplementation for the zero-overhead noop.

build.gradle.kts
dependencies {
    debugImplementation("io.github.yashkasera:alohomora:1.0.0")
    releaseImplementation("io.github.yashkasera:alohomora-noop:1.0.0")
}
2

Apply the Gradle plugin (optional)

Injects build metadata (branch, commit, version, git history) at build time.

build.gradle.kts
plugins {
    id("io.github.yashkasera.alohomora")
}

alohomora {
    enabledVariants = setOf("debug")
    maxCommits = 50
    versionName = project.version.toString()
    versionCode = 1
}
3

Capture network traffic

Add the interceptor to your HTTP client. OkHttp and Ktor are supported out of the box.

OkHttp
val client = OkHttpClient.Builder()
    .addInterceptor(TrafficInterceptor())
    .build()
Ktor
val client = HttpClient {
    install(AlohomoraInspector)
}
4

Enable traffic replay (optional)

Kotlin
Alohomora.registerReplayHandler(okHttpReplayHandler(client))  // OkHttp / Retrofit
Alohomora.registerReplayHandler(ktorReplayHandler(client))   // Ktor
5

Connect the desktop companion

Terminal
./gradlew :desktopApp:run              # Run from source
./gradlew :desktopApp:packageDmg       # macOS
./gradlew :desktopApp:packageMsi       # Windows
./gradlew :desktopApp:packageDeb       # Linux
API
One object, every capability

The entire public API lives on the Alohomora singleton. Every method is mirrored as a no-op in the release artifact.

recordEvent(name, properties?)

Record a named event with optional key-value properties.

recordError(throwable, place?)

Record a caught exception. Also: recordError(reason, stackTrace?, place?) for Swift.

recordTraffic(...)

Manually record a network request with status, URL, method, headers, body, timing.

recordSpan(traceId, spanId, ...)

Record a distributed trace span. Short form: recordSpan(name, durationNanos)

recordFeatureFlag(key, value, ...)

Record a feature flag. Batch: setFeatureFlags(flags, source?)

registerAppDatabase(name, path?)

Register an app database for live inspection.

init()

Initialize Alohomora. Android auto-initialises via AndroidX Startup.

startDevToolsServer(port?)

Start the TCP server for the desktop companion. Default: 53999.

registerReplayHandler(handler)

Register a handler for traffic replay.

isReplaySupported

true if a replay handler is registered. Always false in noop.

registerPlugin(plugin)

Embed custom Compose screens into Alohomora's navigation.

unregisterPlugin(pluginId)

Remove a previously registered plugin by ID.

getPlugins()

Returns currently registered plugins.

Adapters
Bring your own tracer

Alohomora depends on no tracing SDK. Write a ~15-line adapter from whatever you already run.

OpenTelemetry SpanExporter
class AlohomoraSpanExporter : SpanExporter {
    override fun export(spans: Collection<SpanData>): CompletableResultCode {
        spans.forEach { span ->
            Alohomora.recordSpan(
                traceId = span.traceId,
                spanId = span.spanId,
                name = span.name,
                startEpochNanos = span.startEpochNanos,
                endEpochNanos = span.endEpochNanos,
                parentSpanId = span.parentSpanId,
                kind = span.kind.name,
                statusCode = span.status.statusCode.name,
                attributes = span.attributes.toStringMap(),
                events = span.events.map { /* convert */ },
            )
        }
        return CompletableResultCode.ofSuccess()
    }
}

The adapter lives in src/main, compiles everywhere. In release builds, the noop recordSpan discards every span silently.

Mock Rules
Intercept and mock without a proxy

Define mock rules on the desktop, push them to the device. Requests matching a URL pattern return your response instead of hitting the network.

Mock response body with generators
{
  "id": "{{uuid}}",
  "name": "{{name}}",
  "email": "{{email}}",
  "age": {{int(18,65)}},
  "score": {{float(0,100)}},
  "created": "{{iso8601}}",
  "active": {{bool}}
}

Generators resolve per-request. {{uuid}}, {{name}}, {{email}}, {{int(min,max)}}, {{float(min,max)}}, {{iso8601}}, {{bool}}, {{timestamp}}. Unknown placeholders pass through.

  • ›Pattern matching — plain substring or regex against URL + method
  • ›Sessions — group rules into named sessions. Auto-saved to ~/.alohomora/mock-sessions/
  • ›One-click from traffic — right-click a captured request to create a mock with its response pre-filled
  • ›HAR import — import HAR 1.2 files from browser DevTools or Charles/Proxyman
  • ›Export/share — export as .alohomora-mocks.json and share with your team
  • ›Throttle presets — simulate Edge, Slow 3G, Fast 3G, or Slow Wi-Fi

iOS
First-class iOS support

Kotlin Multiplatform means the same library runs natively on iOS with platform-specific adapters.

Ktor (iOS)
let client = HttpClient {
    install(AlohomoraInspector)
}
URLSession (iOS)
let config = alohomoraURLSessionConfiguration()
let session = URLSession(configuration: config)

Swift errors use the recordError(reason:stackTrace:place:) overload since a Swift Error is not a KotlinThrowable.
